# 抚养橘猫约十年至其去世

## 基本信息
- **时间**：小学五年级至大学大二/大三
- **地点**：多个住处（学校附近租的房子、西四环买的房子、东四等）
- **事件类型**：family

## 事件描述
小学五年级时在院子里捡到一只橘色橘猫，一直养了大约10年。猫很胆小，但很懂事。会跟用户一起睡，打雷时钻到用户胳肢窝底下。全家回沈阳时猫自己在家，回来后特别粘人。猫跟随家庭辗转了三个住处。大学大二/大三时猫在东四去世，用户妈妈发现后告知用户，用户哭得非常伤心，最后将猫安葬在附近的土里。
