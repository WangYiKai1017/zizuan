# 青砖缝里的书声

你听——现在还能听见呢，那“吱呀、吱呀”的声音。不是风刮门轴，也不是驴拉磨盘，是咱家老屋西厢房那扇木窗，窗棂子松了，一有风就晃，晃得窗纸嗡嗡颤，像只困在纸后的蜂。我小时候就爱蹲在窗根底下，仰着脸，数那青砖缝里钻出来的细草芽儿，一茎、两茎……数着数着，就听见父亲的声音从屋里飘出来：“人之初，性本善……”

那声音不高，可压得住外头的鸡叫、狗咬、还有远处日本兵皮靴踩在土路上的“咔咔”声。

唉，你说怪不怪？一个三四岁的孩子，哪儿懂什么“性本善”？可那调子，像温水，慢慢往耳朵里淌，淌进骨头缝里。我记不清自己是哪年生的——村里老人说，1931年闹水灾那会儿，我娘在炕上疼了一整宿；可我姐姐后来翻旧账本，又说是1933年开春，槐树刚冒苞的时候。我倒觉得，哪年都行。反正我睁眼看见的世界，就是青砖墙、黄土院、父亲的蓝布衫袖口磨得发亮，还有母亲手背上那一道道裂口，深得能夹住麦芒。

我们家在蓟县东堼村，那时候还叫河北省，没归天津。村子小，百十户人家，一条主街，两边都是青砖灰瓦的老屋。我家那间学堂，原是座关帝庙改的，山门拆了，神像搬走了，剩下三间正殿，梁上还留着褪色的“忠义千秋”四个字。父亲就在那儿教书，教《三字经》，教《百家姓》，也教打算盘。他不是秀才，也没功名，可村里人都叫他“寇先生”，见了面，腰弯得比见保长还低三分。

我三四岁起，就跟着父亲去学堂。不是上学，是“旁听”。他不让我进屋，怕我吵着大孩子。我就蹲在门槛外头，背靠冰凉的青砖墙，看蚂蚁排队搬碎馍渣，听屋里念书。夏天热，蝉在槐树上嘶鸣，汗珠子顺着我脖颈往下滚，痒得钻心；冬天冷，脚趾头冻得发麻，我就把两只小手塞进姐姐给我缝的破棉袄袖筒里，袖口早磨成了毛边，露出黑黢黢的棉花。

可最暖和的时候，是晚上。

天一擦黑，母亲就点起豆油灯。灯芯捻得细细的，火苗黄中带青，照得她脸上一道道皱纹像田垄似的。她一边纳鞋底，一边听父亲教我和姐姐认字。姐姐比我大五岁，扎着两个歪歪扭扭的小辫，手指头被针扎过好几回，血珠子一冒出来，她就赶紧往嘴里一吮，再接着写。父亲用烧火棍蘸了清水，在青砖地上写：“天、地、人、日、月……”水写的字，一会儿就干了，可那笔画，却在我心里洇开，越洇越深。

我记得清清楚楚——那青砖缝里，总有一股潮气，湿漉漉的，带着土腥味儿，还有点陈年墨香混在里面。父亲说，那是老砖吸了三十年的墨气，吸饱了，就往外返。我信。因为我蹲久了，鼻尖贴着砖面，真能闻见那股子微苦又微甜的味道，像晒干的槐花，又像砚台里化开的松烟墨。

那时候，日本人已经来了。不是电影里演的那样，扛着旗、吹着号，是悄没声儿的——先来几个穿灰褂子的“维持会”人，在村口贴告示；后来就换成了戴白手套的宪兵，皮靴锃亮，枪刺雪白，走起路来，连狗都不敢吠。他们逼着学堂教日语，教“大东亚共荣”，教孩子们喊“天皇万岁”。

父亲没教。

他把学堂关了三天，说“修屋顶”。第四天开门，黑板上还是《千字文》：“天地玄黄，宇宙洪荒……”可底下坐着的孩子，少了一半。有些家长怕惹祸，悄悄把孩子领回去了。

那天晚上，父亲没点灯。他摸黑坐在院里那棵老枣树下，手里攥着半截粉笔，指节发白。我蹲在他脚边，听见他叹气，一声接一声，像牛喘粗气。后来，他忽然开口，声音轻得像怕惊飞树上的麻雀：“治协，记住了——字是骨头，骨在，人就不塌。”

第二天起，学堂不开了。可我家西屋的窗，每晚都透出一点微光。父亲把课挪回家，只教我和姐姐。他用烧火棍写，我们用柳枝在地上划；他没有课本，就凭脑子默，一句句背出来，再教我们抄。有时抄着抄着，窗外突然响起一阵杂沓的脚步声，还有日语吆喝。母亲立刻吹灭油灯，我们仨就摸黑坐在炕沿上，大气不敢出。我能听见姐姐的呼吸声，急促得像小鼓点；能听见父亲的手在膝上轻轻敲着节拍，一下，两下……敲的是《千字文》的韵脚。

最怕的是查户口。日本兵来了，端着枪，挨家问“有没有藏抗日分子”。母亲就把我和姐姐塞进灶膛后头的柴堆里——那里头全是干玉米秆，又暖又黑，可满鼻子都是烟熏火燎的焦糊味儿。我蜷着身子，耳朵贴着土墙，听见父亲在堂屋说话，声音平平稳稳：“太君，我们是种地的，不识字，也不懂国事。”他说完，还恭恭敬敬鞠了一躬，腰弯得极低，低得我看见他后颈上那块褐色的胎记，像片枯叶。

后来我才明白，那不是怕，是护。护住我们脑袋里这点墨，护住青砖缝里这点声。

姐姐比我懂事早。她十五岁那年，就学会纺线了。纺车“嗡——嗡——”转起来，像只老蜜蜂在唱歌。她一边摇，一边教我背《论语》：“学而时习之，不亦说乎？”我背错了，她就用纺锤轻轻敲我手背，不疼，但羞得我脸发烧。她说：“爹教的字，是命根子，丢不得。”

可命根子再硬，也挡不住日子的重。我六七岁起，就得跟母亲下地。不是干活，是“陪着”。她锄地，我就蹲在垄沟里拔草；她挑粪，我就拎个小桶跟在后头，桶里装的是她从地头掐来的野菜。那会儿的土，是烫的，赤脚踩上去，烫得直跳脚；也是硬的，锄头砸下去，“砰”一声闷响，震得虎口发麻。母亲的手，指甲缝里永远嵌着洗不净的黑泥，指腹厚厚一层茧，摸上去像老树皮。可就是这双手，在灯下教我描红，在青砖上写“永”字八法，一笔一画，稳如磐石。

有时候收工晚了，月亮升上来，银光洒满麦场。父亲就搬出小凳，让我们坐在场边，指着天上星星讲“北斗七星像勺子，勺柄指的方向，是紫微垣，是天子坐的地方”。姐姐听着听着就睡着了，头一点一点，像啄米的小鸡。我却醒着，盯着那勺子，心想：咱们的天子，还在不在紫微垣里坐着？

现在想起来，我这一辈子，最踏实的时光，就是蹲在青砖缝边，听书声、闻墨气、数草芽儿。那声音没被炮火震散，没被饥荒压垮，它就藏在砖缝里，藏在母亲手背的裂口里，藏在父亲弯下去又挺直的脊梁里。

前些年，我回过一趟蓟县。老屋早没了，原址上盖了新楼，瓷砖锃亮，玻璃反光。我站在那儿，想蹲下去摸摸青砖缝，可脚下是水泥地，冰凉、坚硬、毫无生气。旁边有个穿校服的小姑娘走过，手里捧着平板电脑，屏幕亮得刺眼。

我忽然笑了。

你猜怎么着？我听见了——不是机器声，是风穿过空巷子的呜咽，像极了当年那扇老窗的“吱呀”声。风里，还裹着一点若有若无的诵读声：“人之初，性本善……”

它一直都在。  
只是换了个地方，继续生长。
