- **分层架构**：采用 `Routes` (FastAPI) -> `Runner` (SSE流控) -> `SessionAgent` (状态机) -> `InterviewAgent` (核心逻辑) -> `Tools/Services` (LLM/存储) 的分层设计。
- **状态驱动**：`InterviewSessionAgent` 维护 `SessionPhase` (INIT, PROFILE, INTERVIEW, ENDING)，根据用户是否为新用户自动切换子 Agent (`ProfileCollectionAgent` 或 `InterviewAgent`)。
- **记忆增强机制**：通过 `MemoryCacheTool` 实现短期缓存优先策略，结合 `KnowledgeQueryTool` 进行 Markdown 知识库的深度检索，支持基于关键信息（事件/人物）的动态上下文注入。
- **持久化与归档**：利用 `MemoryArchiveTool` 和 `MarkdownFileManager` 将非结构化对话转化为结构化的事件、人物和时间线，并生成 Session 归档文件以支持断点续聊。
