- 工具类封装模式：对底层服务（如 MemoryManager, KnowledgeBaseQuerier）进行二次封装，形成独立的 Tool 类（如 MemoryCacheTool），提供简化的业务接口。
- Prompt 外部化管理：核心 Prompt 存储在 `Prompts/` 目录下的 Markdown 文件中，通过代码动态加载并注入变量，实现逻辑与提示词的解耦。
- 结构化数据提取：在关键信息识别和问题生成环节，强制要求 LLM 返回 JSON 格式，并通过 `_parse_json_response` 等辅助方法进行容错解析。
- 会话互斥管理：通过单例 `SessionManager` 确保同一用户在同一时间只能存在一个活跃的采访会话，防止状态冲突。
