- **应用入口**：`app.py` 定义 `create_app` 工厂函数，负责注册 CORS、挂载各 Agent 路由（interview, kb_organizer 等）及初始化 LLM 单例。
- **会话控制**：`session_manager.py` 实现基于 `asyncio.Lock` 的单例 `SessionManager`，强制执行“每用户仅一个活跃 Agent”的互斥逻辑，并支持 Interview Agent 实例的持久化存储。
- **流式通信**：`sse_response.py` 封装 `SSEEmitter`，通过 `asyncio.Queue` 协调异步事件生产与 `JSONServerSentEvent` 消费，统一 SSE 协议格式。
- **数据交互**：`routes/files.py` 提供基于 `user_id` 的知识库目录树遍历与文件读取功能，内置路径穿越防护；`schemas/` 目录集中管理 Pydantic 请求模型与字段校验逻辑。
