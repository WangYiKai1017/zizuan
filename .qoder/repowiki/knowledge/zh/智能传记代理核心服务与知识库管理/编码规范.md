- 所有服务类均支持通过构造函数注入 `LLMService` 实例，若未提供则通过 `get_llm_service()` 获取全局单例，以方便单元测试与环境隔离。
- 长期记忆存储统一采用 Markdown 格式，并通过 Wiki Link (`[[path|display]]`) 建立事件、人物与时间线之间的语义关联。
- 涉及用户隐私或特定模块隔离的路径（如 `/biography`）在文件读写和列表操作中均实施了显式的安全过滤与访问拦截。
- LLM 结构化输出均采用 `invoke_structured` 方法配合 Pydantic 模型进行解析，并包含从代码块中提取 JSON 的降级处理逻辑。
